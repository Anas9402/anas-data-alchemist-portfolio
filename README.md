# ANAS.LAB — Data Alchemist Portfolio

Personal portfolio website showcasing my projects, technical skills, education, internship experience, and work in Data Science and Generative AI.

## Tech Stack

* React
* Vite
* JavaScript
* HTML
* CSS

## Featured Projects

### Customer Churn Prediction

Machine learning project for predicting customer churn using Python, Scikit-learn, XGBoost, SQL, and Power BI.

### AI-Powered Spam Detection

NLP-based email spam classification system using TF-IDF and machine learning techniques.

### Hybrid Log Classification

Multi-stage log classification system using rule-based processing, BERT, and LLM-based fallback.

### Mobile Sales Intelligence

Interactive Power BI dashboard for analyzing mobile sales performance and key business metrics.

## Run Locally

```bash
npm install
npm run dev
```

Then open the local development URL shown in the terminal.

## Build for Production

```bash
npm run build
```

The production files are generated in the `dist` folder.
